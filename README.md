# Personal Portfolio Website

A personal website presenting my introduction, education, technical skills, projects, and contact information.

## Technologies
**HTML5 · CSS · Bootstrap**

## Website Sections
- Home and introduction
- About and education
- Technical skills
- Contact section

## Features
- Responsive navigation and page layout
- Contact form interface
- WhatsApp contact button

## Run Locally
1. Clone or download this repository.
2. Open the project folder.
3. Open the HTML entry page in a browser.

## Project Purpose
This project demonstrates foundational frontend development and responsive layout skills while providing a central place to present my work.
