# Personal Portfolio Website

A personal portfolio website that brings together my introduction, education, technical skills, projects, and contact information in one place.

## Technologies
**HTML5 · CSS · Bootstrap**

## Website Sections
- Home and personal introduction
- About and education
- Technical skills
- Contact section

## Features
- Responsive navigation and page layout.
- Contact form interface.
- WhatsApp contact button.
- Dedicated sections to present skills and projects.

## Run Locally
1. Clone or download this repository.
2. Open the project folder.
3. Open the HTML entry page in a web browser.

## Project Purpose
This project demonstrates foundational frontend development skills, responsive page structuring, and the presentation of personal and project information.
